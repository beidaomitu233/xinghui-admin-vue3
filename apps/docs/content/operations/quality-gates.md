# 验证与测试

## 开发检查

| 检查     | 命令                                    |
| -------- | --------------------------------------- |
| 前端类型 | `pnpm --filter @vben/web-ele typecheck` |
| 前端功能 | `pnpm --filter @vben/web-ele test`      |
| 后端     | `mvn -B -ntp clean package`             |
| 文档     | `pnpm docs:check && pnpm build:docs`    |

CI 继续验证应用构建、类型、关键业务和 MySQL/Redis 服务集成。

## 测试原则

优先覆盖业务结果、权限、多角色、持久化、流式协议和实际工具调用。避免为简单组件、纯接口转发与实现细节增加重复断言，不以断言数量作为质量目标。

2.0 移除旧的真实供应商凭据诊断测试与重复界面包装测试；保留受控 HTTP、数据库、会话、权限和 Agent 原生执行验证。新增功能先使用虚构数据验证，再在目标环境做业务验收。
