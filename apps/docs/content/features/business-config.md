# 系统业务配置

统一配置微信、短信、邮件和对象存储。各服务分别保存，按服务商显示适用字段。密钥留空保持原值，需要清除时单独勾选。

## 微信登录

| 场景           | 使用方式                                         |
| -------------- | ------------------------------------------------ |
| 电脑网站       | 点击微信登录，扫码并在手机确认，返回原业务       |
| 微信内 H5      | 发起身份确认，关联产品账号，检查状态后继续原操作 |
| 手机外部浏览器 | 使用密码/短信，或引导在微信内打开                |

网站应用与公众号 H5 分别填写 AppID、回调地址和密钥。接入前先在微信平台完成应用申请、授权域名与回调配置。

扫码状态包含待扫码、已扫码待确认、已确认、已取消、已过期和失败；未完成登录时保留原页面并允许重试。

## 短信与邮件

短信按阿里云、腾讯云等服务商填写签名、模板、区域和凭据。邮件按 QQ 邮箱、企业邮箱或自定义 SMTP 填写主机、端口、加密方式、账号和发件地址。

## 对象存储

选择服务商，填写 Endpoint、Bucket、路径和访问凭据。文件模块通过已生效的配置上传、下载和删除文件。

## 接入状态

状态区用于核对配置是否启用、关键字段是否齐全、服务端是否可读取所需配置。它不代表已经完成真实登录、短信送达或文件上传。实际连通验证从对应服务的测试操作进入。
