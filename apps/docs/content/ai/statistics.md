# AI 统计

入口：**AI 管理 → AI 统计**。统计面向模型选择和企业使用分析，保留对话记录与逐次请求日志。统计默认包含模型推理与连接测试；模型目录读取保留在请求日志中。

## 查看使用情况

选择时间范围、供应商和模型。支持今天、近7天、近30天或自定义31天以内的范围；具备审计权限时可查看全部使用。

| 指标            | 含义                                              |
| --------------- | ------------------------------------------------- |
| 实报费用        | 上游返回的费用，按币种分别统计                    |
| 上游调用数      | 每次实际上游请求；一个业务请求可能产生多次调用    |
| 真实消耗 Tokens | 上游返回的总 Tokens，同时展示采集次数             |
| 输入 / 输出     | 上游返回的输入、输出 Tokens                       |
| 缓存创建 / 命中 | 上游返回的缓存写入与读取 Tokens                   |
| 缓存命中率      | 有缓存数据的调用中，缓存读取 Tokens / 输入 Tokens |
| 首输出          | 从请求发出到首段有效输出，包含平均值和 P95        |
| 耗时            | 请求总耗时，包含平均值、P50/P95                   |
| Tokens/s        | 输出 Tokens / 首输出后的生成时间                  |
| 用户评分        | 请求明细中提交的1至5分评价及样本量                |

未返回的数据展示“—”，费用不混合不同币种。模型、供应商或场景对比要结合采集覆盖率、评价样本和任务类型。

## 趋势与对比

小时趋势可切换 Tokens、请求和费用；下方按模型、供应商、任务场景查看使用情况，也可分析异常分布。表头支持快速排序。

先积累实际使用数据，再比较成本、速度、稳定性与评价，为后续按任务选择模型组提供依据。

## 请求明细与质量评价

请求日志保留请求关联、模型与供应商、Tokens、首输出、耗时、返回状态、原始用量和上游响应。打开有输出的请求详情可评分、填写评价；同一用户再次保存会更新本人的评价。

权限：`ai:request:list` 查看统计，`ai:request:query` 查看明细与评价，`ai:request:audit` 查看审计范围。
