# 故障排查

| 现象           | 检查顺序                                   |
| -------------- | ------------------------------------------ |
| 页面打不开     | 域名、Nginx、容器状态、前端端口            |
| 登录失败       | API 响应、账号状态、验证码、JWT 配置       |
| 菜单缺失       | 用户角色、角色授权、页面路由和组件         |
| 数据库启动失败 | DB_URL、账号、Flyway 历史与迁移错误        |
| Redis 认证失败 | Spring Redis 与 Redisson 配置是否一致      |
| AI 调用失败    | 请求明细错误、供应商地址、密钥、模型可用性 |
| MCP 工具缺失   | 服务工具发现、工具选择、启用状态与执行模式 |
| 知识库无结果   | Dataset ID、API Key、索引状态和检索问题    |
| 统计为空       | 时间范围、当前权限、是否已有真实调用       |

服务器发布状态查看 Actions 和 `/var/lib/xinghui/current.json`。中断发布先核对容器与迁移，再按部署记录恢复。
