# Skill、MCP 与外部知识库

入口：**AI 配置 → 中台设置 → 工具列表**。业务工具、Skill、MCP、外部知识库分开显示。

## Skill

点击“添加 Skill”，填写名称、标识、用途和 Markdown 内容，启用后保存。新任务通过 AgentScope 原生 Skill 仓库读取。

```markdown
# 商品整理

先查看商品字段和在售商品。检查名称、价格与库存，给出需要修改的内容。确认修改结果后，再汇总处理情况。
```

内置 Skill 可查看；自定义 Skill 可编辑。调用权限可填写业务权限码，例如 `sales:report:query`。

## MCP

1. 选择 Streamable HTTP 或 SSE，填写服务地址。
2. 填写密钥。默认使用 `Authorization: Bearer <密钥>`，也可填写服务要求的请求头名称。
3. 保存，点击“读取已保存服务的工具”。
4. 查看工具用途、参数和读写属性，选择启用工具，再保存。

不选择工具表示使用该服务全部可用工具。写入工具默认关闭，启用后仅在“直接处理”模式注册；计划模式只注册服务声明为只读的工具。

协议连接、工具发现和参数转换由 AgentScope 官方 MCP 客户端完成。

## 外部知识库

| 服务    | 服务地址                           | 所需信息                   |
| ------- | ---------------------------------- | -------------------------- |
| Dify    | `https://your-dify.example/v1`     | Dataset ID、知识库 API Key |
| FastGPT | `https://your-fastgpt.example/api` | Dataset ID、API Key        |

添加知识库时填写用途和返回片段数。Agent 通过业务资源目录发现知识库，再使用问题检索，结果包含片段、文档名和评分。

文档上传、切分、索引与知识维护继续在 Dify/FastGPT 中完成。星辉负责接入、检索和在任务中使用结果。
