# 用户管理

用户列表支持关键词搜索、展开筛选、表头排序、导入与导出。操作区在页面背景上，筛选展开时独立承托，表格与分页单独排版。

## 创建和编辑

填写账号、昵称、手机号、邮箱、状态，并选择一个或多个角色。角色下拉支持搜索，保存后列表展示已分配角色。

登录使用手机号。用户可以在个人资料修改自己的信息与密码；管理员可重置用户密码、调整状态和角色。

## 多角色

用户的有效权限是已分配有效角色的授权集合。按职责创建角色，例如“商品运营”“财务查询”，同一用户可同时承担多个职责。

## 批量操作

下载模板、填写用户信息、上传导入，再检查结果；导出按当前筛选条件执行。详见 [导入导出](bulk.md)。
