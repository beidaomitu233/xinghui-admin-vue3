# AI 中台

## 开始任务

1. 在 **AI 配置 → 中台设置** 选择模型顺序，填写 Agent 提示词并启用。
2. 打开 **AI 中台**，新建对话，输入任务；需要识别图片时添加图片。
3. 查看业务结果和任务进度。任务可使用当前账号获准的业务工具、Skill、MCP 和知识库。

用户可以直接说“查看在售商品”“按图片新增商品”“检查微信配置”，无需了解工具名称或接口参数。

## 执行模式

| 模式     | 用途                                           |
| -------- | ---------------------------------------------- |
| 计划     | 先调查和制定步骤，MCP 仅注册只读工具           |
| 直接处理 | 执行业务任务；业务写入展示变更预览，确认后提交 |

MCP 写入工具还需在扩展设置中启用。业务结果以工具回执展示，不把内部重复工具事件逐条铺在聊天中。

## 会话与消息

左侧可搜索、切换和管理对话。用户消息支持复制与修改后重新发送；助手输出支持 Markdown。计划卡片展示步骤与当前阶段。历史对话和调用明细统一在 **AI 统计** 查看。

## 调整助手

系统提示词管理助手职责和业务背景；Skill 保存可复用的操作指引；工具提供可执行动作。更换业务时，优先增加工具与 Skill，再调整提示词。
