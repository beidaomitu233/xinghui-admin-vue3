# 角色与权限

## 分配权限

打开角色编辑，填写角色名称、标识和状态。权限区按一级分类展示，支持名称/权限码搜索、展开收起和当前分类全选。选中节点单独保存，不自动扩大为所有子权限。

## 页面、模块与动作

| 类型       | 用途                   | 示例                   |
| ---------- | ---------------------- | ---------------------- |
| M 目录     | 菜单分类               | 业务                   |
| C 页面     | 路由与页面入口         | 订单管理               |
| G 业务模块 | 页面内功能分组，可嵌套 | 退款、结算、导入导出   |
| F 操作权限 | 具体业务动作           | 审核、退款、结算、导出 |

```text
订单管理（C）
├─ 查询订单（F：orders:order:list）
├─ 退款（G）
│  ├─ 申请退款（F：orders:refund:apply）
│  └─ 审核退款（F：orders:refund:approve）
└─ 结算（G）
   └─ 发起结算（F：orders:settlement:execute）
```

权限名称不限于增删改查。G 只组织权限，不生成菜单路由。前端按钮和后端接口使用同一个动作权限码；Agent 调用业务服务时复用该授权。

一个用户可分配多个角色，多个角色的有效权限合并。
