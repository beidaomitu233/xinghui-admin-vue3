# 表单管理

## 设计和发布

1. 新建表单，填写名称和用途。
2. 在可视化设计器拖拽字段，设置标签、必填、选项和校验。
3. 预览填写效果，保存并发布。

已发布版本用于填报；设计草稿可以继续调整，确认后再发布新版本。

## 填写和分享

从记录页填写表单，或创建分享入口给他人填报。分享设置控制可访问范围与有效状态；提交结果进入记录列表。

记录页支持查询、排序、详情与授权编辑。自定义业务可在表单基础上增加业务服务和 Agent 工具。

## AI 摘要

配置记录摘要场景后，从记录详情发起 AI 总结。可以把结果填入编辑草稿，由用户检查并保存。

开发扩展见 [表单扩展](../development/lowcode-extension.md)。
