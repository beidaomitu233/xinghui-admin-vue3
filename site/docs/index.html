先选一个阅读入口 ​

这份文档面向管理人员、业务使用者、开发者和部署维护者。阅读公开文档不需要登录；操作管理应用仍需要有效登录、操作权限和符合接口要求的身份。

你的目标从这里开始正常结果
首次运行项目快速开始 → 运行验证连接自己配置的数据库、缓存和 API，完成登录与最小验证
使用管理页面功能手册 → 四个菜单组能找到当前身份实际获权的入口，不把菜单显示当成服务端授权
新增功能项目结构 → 新增模块知道应修改哪层代码、怎样增加迁移和验证权限
复用页面组件组件概览找到本项目实际适配与组件契约，而不是照搬上游示例
上线或升级部署 → 备份恢复 → 升级形成可回滚、可核验的部署组合
确认交付状态候选版本 → 质量门禁区分代码实现、本地验证、供应商联调与正式 CI

怎样检索 ​

点击顶部“搜索文档”，或按 Ctrl+K（macOS 使用 ⌘K），输入功能名称，例如“字典管理”；部署配置可搜索 CONFIG_MASTER_KEY。结果来自随站点发布的本地全文索引，无需外部搜索服务。选择结果进入章节，右侧“本页目录”可直接跳转到具体规则。按 Esc 关闭搜索。

如果没有结果，换用页面实际名称或配置键，去相应分类侧栏查找。静态站点离线缓存未更新时，应刷新页面并确认应用与文档的候选版本匹配；不要为了查文档删除登录存储。

文档与运行状态 ​

本次 Pages 发布目标为后台静态演示和文档中心，实际部署状态以公开仓库 Actions及 HTTP 验收为准。静态演示使用浏览器本地示例数据，不连接真实后端或供应商；这次发布不等同后端正式发行或完整应用质量 CI。

v1.2.0是已发布静态旧快照；当前源码组合的一期AI已通过正式CI、MySQL5.7/8.0服务矩阵与真实记录摘要闭环，尚未为该AI源码建立独立发行Tag。源码默认四个一级组为系统管理、通用能力、运行维护、AI管理；实际显示仍按身份授权过滤。页面存在不代表所有供应商已接通，真实微信扫码、短信发送与独立机器验证仍有边界，见能力清单。Agent与插件执行尚未交付。

文档只有一个正文来源：前端仓库 apps/docs/content/。默认静态基路径为 /docs/，子目录托管可通过 DOCS_BASE 设置完整路径；章节使用 .html 地址。默认“文档中心、当前页面帮助、版本说明”入口不携带用户信息或 API 凭据。部署失败时按故障排查检查静态目录和反向代理，不把文档 404 当成登录失效。
