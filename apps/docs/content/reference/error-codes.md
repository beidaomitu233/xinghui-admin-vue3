# 错误处理

| 类型              | 页面处理                               |
| ----------------- | -------------------------------------- |
| 未登录 / 登录失效 | 重新认证后返回原页面                   |
| 无权限            | 保留上下文，提示缺少权限               |
| 字段错误          | 在对应表单项显示说明                   |
| 版本冲突          | 重新读取当前记录并确认修改             |
| 服务不可用 / 超时 | 保留输入，提供重试                     |
| AI 请求失败       | 展示任务状态，在请求明细中定位上游错误 |

Agent 的业务失败会作为工具结果交给助手处理；服务端日志与请求 ID 用于定位实际故障。
