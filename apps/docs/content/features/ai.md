# AI对话、模型配置与数据库引用

AI管理的调用监控（`/ai/requests`）用于查看对话记录和继续追问；提示词配置（`/ai/templates`）用于编辑场景与数据引用。模型设置从对话工作区进入。场景合法保存后直接供新调用使用。

本页描述对话持久化、简化模型设置与实际数据库引用改造，仍待整体组合验收及发布。此前一期的验收与供应商失败记录见[版本页](../releases/versions.md)，不能当成本次改造通过的证据。公开演示使用虚构数据，不连接真实模型。

## 填写Key并选择模型

在设置中填写配置名称，选择服务商，使用默认API地址或填写自己的服务地址。API Key使用密码输入框；按名称选择建议模型，也可填写服务商实际模型代码。界面不要求填写内部模型/密钥/配置版本ID或协议枚举。

保存已有配置时，Key留空表示保留原值；需要更换时输入新Key。保存后仅显示已配置和尾号标记，刷新后仍可确认配置状态。完整Key不回显、不进入浏览器持久化或对话消息。

保存不自动调用供应商。明确点击测试连接才发起模型测试，查看具体结果；限流、超时、认证失败和部分成功不算完整成功。选择成功后启用时，只有仍对应当前配置的完整成功结果才能更新可用配置，失败保留原已可用配置。测试与启用仍分别授权。

## 查看和继续完整对话

从会话列表按可读标题、场景及最近时间找到对话，打开后按顺序查看用户消息、回答和真实状态。输入问题开始新会话，在同一会话中继续追问；后续模型上下文包含此前成功的问答轮次。

新对话正文保存在服务端，刷新或重新登录后可继续查看。失败、取消与部分输出如实保留，失败内容不会冒充完整回答参与后续上下文；同一会话有一轮正在执行时，等待或取消该轮后再提交新问题。请求受理不等于生成成功，断线应查询原请求，不自动重复生成。

历史上下文有轮数和容量上限，截断会说明从何处继续使用；展示历史不会因此删除。旧请求没有保存正文时显示“旧记录未保留对话”，系统不会补造回答。技术统计与请求详情可按需展开。

默认只能查看自己的对话。平台审计查看他人的记录需独立审计及查询权限；查看权限不允许冒充本人续聊。会话详情、续聊、正文、事件与取消都在服务端检查本人、租户、场景及实际数据权限。

## 编写提示词并引用真实数据

1. 在左侧选择或新增场景。记录摘要按名称绑定表单，普通场景可不取数，也可选择数据库来源。
2. 在右侧编辑完整提示词。历史非空输出要求会合并进正文供继续编辑；新界面使用同一个编辑器。
3. 打开数据引用选择器，按表备注和表名找到业务表，再按字段备注、字段名及类型选择内容。低代码表单展示实际schema中的所有可读业务字段。
4. 选择下列取数方式和有权记录，预览实际值、条数及截断提示，然后一键插入可读变量，例如 <code v-pre>{{客户.名称}}</code>、<code v-pre>{{订单明细}}</code>。不需要手写SQL、绑定JSON或内部ID。
5. 编辑停止后自动保存；只有服务端确认当前内容后才显示已保存。保存仅静态校验定义，不读业务样本、不测试Key或调用模型；试运行时才按当前真实身份读取数据并调用模型。

| 取数方式 | 操作与实际结果                                                   |
| -------- | ---------------------------------------------------------------- |
| 单行字段 | 选择一条记录和一个字段，得到该字段实际值                         |
| 整条记录 | 选择记录及全部可读字段，得到对象，秘密字段排除                   |
| 整表数据 | 选择字段、可选过滤和数量上限，得到实际行数组；不会无限制装载整库 |
| 关联子表 | 选择主记录、子表及真实关联字段，得到属于该主记录的具体子行       |

关联可从真实单列外键选择，也可明确选择兼容的主/子字段。子查询实际使用主记录的关联值，并同时执行子表的过滤、租户和软删除条件；显示关联结构不代表已获取数据。

预览展示普通有权业务值，数字、null、对象和数组保持结构。值只替换一次，其中的花括号不会再次渲染；业务值不会成为SYSTEM指令、SQL或脚本。数据库密码、Key、令牌、认证配置等秘密不会进入上下文。

每个引用最多200行，最多16个引用、64个字段和16个AND过滤；总结果受容量与时限限制。普通长文本字段可能截断并提示，无法安全解析或超限的结构化数据会明确失败。当前版本从实际基础表读取，复合外键不会被当作单列完整关系；无可读主键的表可有界整表读取，不能假装可精确选择单行。

## 数据权限与恢复

通用数据库读取需明确的数据库读取权限及平台身份。保存一个引用不会把该表授权给其他业务调用者或租户；运行时继续核对当前账户、租户、软删除和已知业务权限。低代码读取沿用记录query/list与真实租户范围。

新保存固定字段及取数定义；表后来新增列不会自动加入已保存的全字段引用。未知或删除的表/字段、无权记录或不兼容关联会明确失败。低代码按记录原schema读取，新字段尚未存在于旧记录时返回null并给出提示。

保存失败保留本地输入；无效输入不替换上次有效配置。409冲突时保留编辑并明确处理，不静默覆盖。模型暂不可用允许保存合法配置，但运行前仍需恢复可用模型。正在执行的请求继续使用受理时固定版本。

## 记录摘要与旧配置

低代码记录摘要同样进入对话记录。具有业务调用和记录读取权限时生成，可继续追问、取消或复制。完整成功结果需用户显式填入长度合适的文字字段草稿，再检查并点击原表单保存；不会自动写入业务记录。

旧场景仍保留精确版本、共享模板和原批准资源范围。支持的旧模板首次转换前展示差异并明确确认；特殊默认值、截断、无法保留的必填/长度策略仍只读保留。新增通用数据库绑定不能绕过旧资源审批；需要使用新原生场景及独立数据库读取权限。

旧AI02读取链路与历史请求保留。Agent、插件、工具执行和审批写入仍未交付。技术合同见[场景与数据扩展](../development/ai-extension.md)及[API目录](../reference/api-catalog.md#数据库引用与实际值预览)。
