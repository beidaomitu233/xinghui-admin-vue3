## 当前能力范围

- 登录/用户角色菜单、平台身份与操作码、字典、参数、文件与受控批量操作。
- 安全调度handler与执行诊断、站内通知模板/事件和本人收件箱。
- AI模型元数据、环境/数据库凭据及受控模型测试；多应用场景草稿/发布/变量预览、注册业务上下文的prompt读取接缝。
- 微信PC网站授权发起、state/cookie/callback边界；**完整微信绑定登录尚未交付**，无AppID/资格的外部扫码验证暂缓。
- 微信/SMS/OSS统一业务配置、加密密钥、revision与历史存储读取；低代码七种字段、发布schema、记录CRUD/冲突与租户范围。
- 菜单合并为“系统管理、通用能力、运行维护”，普通登录者保留本人收件箱，中性工作区主题与强调色区分。

通用资料示例、网站内容管理、下载、页面业务模块已退役；资讯/公告等保留业务仍存在。数据库历史迁移保留退役链路，不代表旧模块仍可用。没有部门/岗位体系、匿名低代码公开填写、附件/复杂联动或两个独立真实业务系统采用证明。

## 选择部署组合

先读取对应仓库提交和迁移目录，再执行冻结安装/严格测试/实际构建，记录JAR、dist及文档dist的摘要。升级前比对数据库history与目标migration location，按[升级](./upgrade.md)准备恢复点；需要功能细节时读[变更说明](./changelog.md)。

若运行环境的行为与本文不一致，首先确认是否是这份代码和产物：旧dist、错API地址、旧数据库或个人配置覆盖都可能使页面看起来“同版本”却不是同一组合。文档不通过修改版本号字符串代替源码配对。
