# 加载与反馈

| 状态         | 推荐组件             |
| ------------ | -------------------- |
| 首次内容加载 | ElSkeleton           |
| 表格刷新     | 表格 Loading         |
| 按钮提交     | Button Loading       |
| 操作成功     | ElMessage.success    |
| 可恢复失败   | ElAlert 与重试操作   |
| 无数据       | ElEmpty 或表格空状态 |

沿用组件默认动画和主题色。失败时保留表单输入；保存未确认前不展示成功。
