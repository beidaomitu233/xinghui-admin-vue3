# 资讯模块退役说明

USE-05删除资讯管理页面、API、权限菜单、专属 `sys_news` 表及服务实现。原菜单和API不再提供资讯CRUD，通知公告 `SysNotice` 保留。

V20261023_330以新增向前迁移执行退役，旧迁移校验和不变。SQL数据目录不再发布资讯数据集，通用数据库读取也显式拒绝 `sys_news`，旧AI配置不能借移除权限映射扩大读取范围。需要迁移历史资讯数据的部署，应在正式执行删表迁移前按项目备份流程保存；不在生产手动运行临时DROP。

新模块开发参考[字典与模块扩展](../development/module-extension.md)，通知能力见[通知中心](notifications.md)。
