AI调用监控与提示词配置 ​

AI管理提供两个日常入口：调用监控（/ai/requests）和 提示词配置（/ai/templates）。模型与Key设置从调用监控内进入。系统按场景组织提示词和调用规则，合法配置直接保存生效。

本页描述一期工作区改造的操作与约束，对应源码、独立验收结果和本轮免费模型超时限制见版本页。公开静态演示使用虚构数据，不连接真实模型；实际公开内容以已审核部署的产物为准。

配置一个场景 ​

  1. 打开“提示词配置”，在左侧搜索、选择或新增场景。记录摘要场景按名称选择真实表单；通用场景可以不选择数据对象。场景标识由服务端生成，名称可修改，绑定表单和场景种类固定。
  2. 在右侧填写场景名称、用途和宽幅提示词正文，可补充输出要求。按名称选择模型，按需调整允许的Key与调用限制。模型和Key的当前可用状态会影响运行。
  3. 如需读取记录，选择内置“低代码表单记录”和允许字段。当前仅支持实际表单结构中存在的 subject、summary；internal_note 和其他新增字段不会自动进入上下文。字段及样本候选需另具业务读取权限。
  4. 停止编辑约600ms后自动保存。只有服务端确认当前内容后才显示“已保存”。合法保存创建不可变执行快照，后续新请求使用该快照；正在执行的请求继续使用受理时版本。停用场景保存后仍保持停用。
  5. 具备场景测试和业务调用权限时，需要检查结果可展开同页试运行区域，选择有权记录并填写用户输入。预览仅授权取数和脱敏展示；明确发起模型试运行才会调用供应商，可能计费。试运行不作为保存前置。

提示词可使用 {{user_request}}；勾选字段后可使用 {{record_subject}}、{{record_summary}}。变量只替换一次，值中的占位符不会继续展开。业务投影值进入USER消息，独立JSON消息保留原数字、布尔和null类型；它们不会成为SYSTEM指令、SQL或脚本。

正文与输出要求合计最多32000字符，用户输入最长2048字符。未选择的字段变量、未知变量或未闭合占位符会给出局部错误。样本仅帮助选择和试运行，保存静态配置不读取样本正文、不测试Key、不调用模型。模型暂不可用仍可保存合法配置，并显示不可运行原因。

保存失败与冲突 ​

状态如何处理
保存中或有更新输入等待当前内容的服务端确认；旧响应不能覆盖较新编辑
字段或语法错误保留本地输入，修正对应位置；上次有效配置继续明确显示
网络失败保留输入，按提示重试；未确认前不能称为已保存
HTTP409版本冲突保留本地内容，读取最新版本并明确选择如何处理，避免覆盖他人修改
尚无有效配置完成第一份合法配置后才能运行
停用或模型不可用按具体原因恢复；保存成功不代表供应商当前可用

管理场景的权限不会赋予记录读取或业务调用权限。新增场景不授予任意SQL、URL、Bean、脚本或动态取数能力；未获权候选不会返回名称或总数。

调用监控与Key设置 ​

调用监控展示请求、尝试、状态及安全错误分类，可按时间、场景、模型与结果过滤。请求数和尝试数分别统计，业务调用与配置测试分别展示。默认OWN范围只看当前身份可访问的数据；AUDIT还需平台身份、独立审计权限及对应查询动作。

“当前启用Key”按当前ACTIVE配置中有效准入搭配的Key版本去重；“近24小时调用异常Key”只统计这些当前Key版本在窗口内真实失败尝试的交集。取消、模型调用前的输入或取数失败不算Key异常。缺少Key版本的旧尝试单列未归属，未知用量或无权统计保持未知，不能解释为0、实时健康、余额或费用。

从监控进入单层模型与Key设置区。凭据显式保存、测试和启用，分别受动作权限限制；提示词自动保存不会保存或测试Key。Key只写不回显，关闭设置后清空未提交的凭据输入。只启用测试准入的搭配；外层HTTP成功不等于供应商测试成功，仍应查看具体测试结果。

日志查询、刷新和导出只读取元数据，不重发模型请求。日志不保存提示词、输入输出正文或密钥。供应商限流、超时和输出中断须保留真实结果，不能用演示内容补成成功。

低代码记录摘要 ​

管理员在提示词配置中为表单保存有效摘要场景后，具有业务调用和记录读取权限的用户可从记录入口生成摘要。页面按名称选择，不要求填写应用ID、模板/资源版本ID或 formId:recordId。服务端按当前身份、租户、表单及记录重新读取，使用记录原始schemaVersion和允许字段。

  1. 在有权记录上打开“AI摘要”，填写摘要要求并生成。
  2. 查看原请求ID、场景版本和明确状态。受理成功、部分文字或连接关闭都不等于生成成功。
  3. 断线或刷新后查询原请求；不要因结果不明而重复生成。历史正文未保存且短期事件已过期时无法恢复，不自动重发。
  4. 收到完整成功结果且具有记录编辑权限后，选择长度合适的文字字段，显式“填入编辑草稿”。核对内容后点击原表单“保存”，才写入记录。

生成、取消或复制都不会自动写入业务记录。Agent审批写、插件执行、工具调用和持久会话仍未交付。记录操作及恢复见低代码表单。

旧配置与转换 ​

已有v0.4发布应用按精确旧版本建立兼容映射，继续保留原请求历史、共享模板及已批准资源范围。未发布草稿不因升级而启用；歧义映射会明确不可用，不按名称或最大ID猜测。旧AI02的appKey/sceneKey链路保持独立。

支持转换的旧模板先展示原分区消息和转换差异：单编辑器将内容组合为USER消息，内置读取保留null。首次保存需明确确认转换差异，服务端收到confirmedLegacyConversion确认后生成场景自己的快照，不修改其他场景共用的旧模板。特殊默认值、截断策略、无法保留的必填/长度限制、额外变量或不支持的数据映射保留原配置并只读说明原因，不能静默丢弃再转换。

每次后续保存都以同一精确旧基线验证资源、字段、原应用和允许主体范围；勾选内置字段不能扩大原审批。原资源撤销、停用或证据失效仍会阻止读取。已被场景接管的旧应用/模板写接口返回HTTP409 SCENE_MANAGED，应回到提示词配置编辑；旧不可变版本和历史保持可读。

技术接口与旧链路边界见AI扩展和API目录。
