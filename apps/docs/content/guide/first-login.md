# 首次登录

## 初始化账号

新库种子账号使用手机号登录：管理员 `13800000000`，演示账号 `13800000001`，初始化密码均为 `admin123`。

1. 首次登录后修改管理员密码和手机号。
2. 根据需要停用演示账号。
3. 创建业务角色，分配菜单、模块和操作权限。
4. 创建用户，可选择多个角色。

## 登录方式

桌面登录页同时显示账号密码与微信扫码，可切换短信登录。微信和短信需要先配置相应服务商；短信登录用于已有且启用的产品账号。

验证码开启后，登录表单展示图片验证码。密码登录接口为 `POST /user/login`，请求字段为 `phone`、`password`，启用验证码时追加 `code`、`uuid`。

## 开始配置 AI

添加供应商 → 获取上游模型 → 建立业务模型 → 设置提示词/中台模型顺序 → 发起任务。参见 [模型与提示词](../features/ai.md)。
