# 功能概览

| 模块 | 主要功能 |
| --- | --- |
| AI 中台 | 自然语言与图片任务、会话、计划、进度、业务变更确认 |
| AI 配置 | 业务模型、多供应商、多密钥、模型目录、调用顺序、中台设置 |
| 提示词 | 场景、模型排序、结构化数据引用、数据库查询引用、试运行 |
| AI 统计 | 费用、Tokens、缓存、首输出、耗时、趋势、模型对比、用户评分、请求明细 |
| 账号 | 用户、多角色、角色权限、个人资料、密码/微信/短信登录 |
| 系统 | 菜单、字典、参数、微信/短信/邮件/对象存储配置 |
| 业务 | 可视化表单、填报与分享、文件、通知公告 |
| 运维 | 定时任务、调度日志、操作日志、自动部署 |

进入具体功能前，先给账号分配对应角色。菜单、按钮和 Agent 使用同一套业务授权。
