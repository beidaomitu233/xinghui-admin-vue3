# AI 中台聊天页接入

本分支 `feature/AI-HUB-20261025` 嵌入官方 `@agentscope-ai/chat@1.1.72` 的完整 `AgentScopeRuntimeWebUI`。聊天输入、图片附件、消息、Markdown、会话状态、响应操作和侧栏布局沿用官方页面。

## 会话面板

`hub-sessions.ts` 使用同一官方包的 `HistoryPanel`（Conversations）提供搜索、时间分组、行内重命名和归档。持久化仍走原登录用户的会话 API；重命名使用已加载版本，避免把另一个客户端的新名称无条件覆盖。

原整页组件没有会话列表插槽，使用 pnpm 的锁定版本补丁 `patches/@agentscope-ai__chat@1.1.72.patch` 增加两个可选字段：

- `session.renderList`：保留原生可收起侧栏和新建按钮，替换其列表内容为官方 `HistoryPanel` 的业务适配。
- `session.newChatLabel`：本地化原生新建按钮。

补丁还补齐官方行内输入的 Enter 保存、Esc 取消及输入法合成保护。窄屏时即使没有配置右侧标题，也保留原生会话抽屉入口；不重写编辑或侧栏组件。默认调用方式保持兼容。

`api.emitResponseWithoutContent` 是可选兼容开关，默认关闭。本页开启它，使仅含阶段、步骤和业务预览的响应也进入官方响应卡；否则 SDK 会在正文生成前丢弃此类帧，模型等待确认时用户无法看到确认按钮。正文、Markdown 和响应操作仍由官方组件渲染。

补丁由 `pnpm-workspace.yaml` 的 `patchedDependencies` 和 `pnpm-lock.yaml` 共同锁定，正常安装和 CI 会自动应用；升级 SDK 时必须重新检查补丁。不要直接改共享 `node_modules`。

## 产品分支

- AI 中台入口仅从后端已授权菜单中提升到第一位；不为未授权账号生成入口。
- 有 Agent 调用权限的账号以中台为首页，其余账号继续原首页/可访问页面。
- 浏览器存储命名空间增加 `-ai-hub` 后缀，隔离普通产品的登录、标签页和偏好；服务端会话历史不因换命名空间删除。
- 普通产品分支保持原来的 AI 辅助界面和导航。
