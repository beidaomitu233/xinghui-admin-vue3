# 模型与提示词

## 模型和供应商

**AI 配置 → 供应商** 中新增供应商渠道和密钥，从供应商实时目录选择上游模型。每个渠道分别保存密钥、可用模型与调用策略。

**模型** 页维护业务模型。一个业务模型可连接多个供应商；相同模型的多个接入用于可用性和费用选择。业务模型卡片显示接入状态，供应商策略在供应商管理中修改。

## 提示词场景

1. 新建场景，填写名称与用途。
2. 选择业务模型，拖拽调整调用顺序，配置兜底。
3. 添加数据引用，将引用标记插入提示词。
4. 保存并试运行。

数据引用可以是用户输入、业务表单记录、字典或数据库查询。预览数据只读取引用；试运行才调用模型。

## 在业务中调用

在业务页面提供用户输入与当前记录，通过已发布场景发起请求。模型与供应商切换由后端处理，页面消费流式结果。

Agent 使用独立的 Agent 场景提示词，在中台设置中统一管理模型顺序与职责。详见 [AI 中台](../ai/workbench.md)、[开发业务工具](../development/ai-extension.md)。
