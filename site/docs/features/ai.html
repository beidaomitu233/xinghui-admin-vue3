AI模型、提示词与业务场景 ​

入口为 通用能力 → AI模型、提示词场景。模型管理和场景设计需要平台身份及 ai:model:* / ai:prompt:* 精确权限；业务读取由代码注册的应用权限控制，不自动获得管理权限。

模型操作 ​

在模型页点击“新增模型”，填写“供应方标识”“模型代号”“HTTPS 服务端点”“凭据环境变量名”“超时（秒）”，并选择启停状态。仅使用已获授权的模型信息。技术请求字段分别为providerCode、modelCode、endpointUrl、credentialEnvName、timeoutSeconds、enabled。凭据来源为ENV或加密DB，GET仅返回配置标记；数据库模式要求稳定CONFIG_MASTER_KEY。更新、启停、删除及凭据保存携带revision，冲突后重新读取，不覆盖他人的最新修改。

模型测试当前仅支持官方OpenRouter端点。点击模型行“测试模型”后，必须看结果内容，不能只看API返回200。当前Controller将测试Outcome放入Result.ok：例如外层HTTP200/code200，内层 data.outcome="RATE_LIMITED"、data.httpStatus=429，代表供应方调用失败于限流。只有SUCCESS才是模型测试成功；AUTH_FAILED、MODEL_MISMATCH、TIMEOUT等各有不同恢复方式。测试可能调用外部供应商并产生计费，须在部署与授权明确后使用，不因教程示例自动发请求。

场景流程 ​

  1. 打开新增场景草稿，在“应用标识”填写 example_app、“场景标识”填写 summary，选择一个已有“启用模型”。这里的example_app只是中性设计示例，未注册业务resolver时不能运行读取。
  2. 在“提示词草稿”填写 概述：，点击“添加变量声明”，填写变量名subject，类型选择“文本”，用途说明填写“中性主题”，示例值填写“界面调整”。
  3. 点击“保存草稿”，从列表“预览”进入“场景中性预览”，点击“生成中性预览”；应得到“概述：界面调整”。预览是文本渲染，不是模型调用，敏感变量会掩码。
  4. 点击列表“发布”并确认，详情中的“已发布快照”应出现版本。业务使用published版本；再次编辑“提示词草稿”不改变已发布内容。发布与启停使用revision。

占位符使用 ；类型“文本/数字/布尔值”分别对应STRING/NUMBER/BOOLEAN，变量声明含description、sensitive、exampleValue。变量未声明、缺值或类型不符时先修正声明和输入，不把预览错误当成供应商连接错误。

正文最长12000字符、最多64变量；单个预览/运行变量最长2048字符，exampleValue最长512。appKey/sceneKey创建后稳定，不能靠改名复用其他应用资源。

业务读取与恢复 ​

POST /ai/scenes/{appKey}/{sceneKey}/render只渲染已注册应用、已发布启用场景。接缝验证认证、业务动作、资源归属与租户，然后解析变量；不会直接发送模型请求或保存业务正文。未注册应用、缺变量、越权、停用场景与输出超长有明确拒绝结果。

没有证明两个独立业务系统已实际采用，也没有通用聊天、自动Agent或任意SQL/脚本变量能力。新业务注册方式见AI扩展。
